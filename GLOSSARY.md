# Starter Workspace

The workspace gives a user one place to organize structured information, edit Markdown, and manage uploaded files.

## Language

**Record**:
A structured entry in the workspace with a title, category, status, and optional descriptive details.
_Avoid_: Item, when referring specifically to a Record

**Markdown Document**:
A written workspace document whose source is Markdown, with optional descriptive metadata in frontmatter.
_Avoid_: Note, page

**Document Summary**:
The title, tags, indexing status, and other descriptive information shown for a Markdown Document in the library.
_Avoid_: Document body, abbreviated document

**Asset**:
An uploaded file available for reuse on its own or in a Record or Markdown Document.
_Avoid_: Attachment, when the file has no association
