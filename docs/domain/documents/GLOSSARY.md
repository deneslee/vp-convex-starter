# Documents

This context describes Markdown content and the information users see in the library and editor.

## Language

**Document**:
An authored item with a title, Markdown body, and optional descriptive information such as tags and frontmatter.

**Document Summary**:
The identifying and descriptive information used to browse the library. It includes the title, slug, frontmatter, tags, and Indexing Status.

**Document Detail**:
The complete view of a Document, including the Markdown body.
