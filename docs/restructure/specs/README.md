# Specs

This folder holds one small spec per implementation step, named `<phase>-<step>.md` (for example `P2B-3-appframe-recordtable.md`). It is written when that step is next.

The template and the step routine are in [../workflow.md](../workflow.md). Steps P2B-1 and P2B-2 were done before this system and have no spec.
